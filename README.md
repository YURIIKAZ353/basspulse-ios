# BassPulse — прототип для iPhone

Версия 0.1.6 (сборка 7) возвращает непрерывное воспроизведение AVAudioEngine по умолчанию, без нарезки музыки на PCM-участки. Подтверждённый пользователем результат 0.1.5: музыка продолжалась в фоне, вибрация исчезала в обоих режимах, в звуке были тихие щелчки. Совместный проигрыватель 0.1.5 сохранён только для сравнения.

Новый вариант `liveShared` сочетает непрерывную музыку с Core Haptics в общей аудиосессии (`playsHapticsOnly=false`). Он использует синтезированный `audioContinuous`, как успешный тест 0.1.4, но с нулевой громкостью по умолчанию. Для непрерывной вибрации аудиоэлемент входит также в один паттерн с hapticContinuous; короткие удары тоже содержат аудиоэлемент. Настройки частот и силы снова применяются в реальном времени. Это гипотеза, а не подтверждённое исправление: нулевая громкость ещё не проверена на iPhone.

Для сравнения есть переключатель «Тихий тестовый тон»: он возвращает громкость синтезированного элемента 0.03. Меняется только после остановки музыки. Если вибрация в фоне работает только со слышимым тоном, это нужно сообщить отдельно: такой результат сам по себе не выполняет требование о неизменённом звучании музыки. Дополнительный фиксированный тест `sharedSilent` повторяет 12 импульсов с audioContinuous нулевой громкости, чтобы отделить работу аудиоэлемента от живой реакции на музыку. Отчёт фиксирует фактический способ и громкость элемента.

Версия 0.1.5 (сборка 6): новый режим «Музыка и вибрация в одном движке» включён по умолчанию. После подтверждённого пользователем успеха sharedAudio-теста в фоне и при блокировке он переносит саму песню в Core Haptics через небольшие PCM audioCustom-ресурсы. В каждом паттерне находятся участок настоящей музыки и рассчитанные по частотам тактильные события/огибающая. Искусственного тона и равномерных тестовых ударов в обычном воспроизведении нет.

Подготовка идёт секундными участками с очередью до трёх. Это ограничивает память и позволяет менять настройки без перезапуска песни: частоты, порог, сила, режим и резкость применяются к следующим ещё не подготовленным участкам, примерно до 3 секунд. Выключатель вибрации немедленно отключает тактильный вывод всего движка. Поправка синхронизации задаёт относительное смещение аудио и вибрации на общей шкале времени; автоматическая прибавка задержки Bluetooth в новом режиме не применяется. Сначала проверь значение 0 мс, затем подстрой по ощущениям.

Секундные участки воспроизводятся один за другим по времени Core Haptics; старые ресурсы освобождаются. Проверка на GitHub сравнивает сэмплы всех подготовленных файлов с исходником, проверяет непрерывные исходные смещения, последний неполный участок и применение выключенных полос к следующему участку. Она не доказывает отсутствие слышимых стыков, точность Bluetooth или физическую фоновую вибрацию — это проверяем на iPhone. Если планировщик опоздает, отчёт содержит `combined scheduling underrun`.

Новый режим пока поддерживает моно/стерео. Прежний AVAudioEngine-проигрыватель оставлен для сравнения: останови музыку и выключи переключатель нового режима. Отдельные экспериментальные тесты доступны только в прежнем режиме. Для проверки версии 0.1.5 используй обычное «Играть», а не тестовые импульсы. Приложение всё ещё работает со своими файлами; захват Spotify/YouTube пока не реализован.

Версия 0.1.4 (сборка 5) — сравнительный эксперимент доступных публичных API. В диагностике выбери один способ и запусти 12-секундный тест во время музыки:

- Core Haptics: исходный — прежний режим `playsHapticsOnly=true`, общий AVAudioSession.
- Core Haptics: общая аудиосессия — `playsHapticsOnly=false`, общий AVAudioSession, один паттерн с настоящим тихим аудиотоном и 12 тактильными импульсами.
- Core Haptics: своя аудиосессия — инициализация `CHHapticEngine(audioSession: nil)`, аудиотон и 12 импульсов. Маршрутизация звука может отличаться от общего аудиовыхода.
- System Sound — шесть вызовов публичного `AudioServicesPlaySystemSound(kSystemSoundID_Vibrate)` через две секунды. Этот API не позволяет задавать силу; тест проверяет только физическую вибрацию в фоне и не заявляется заменой полноценной настройки басов.

Обычная вибрация под музыку приостанавливается на время опыта и возвращается после него. Нажатие «Стоп» отменяет оставшиеся команды. В аудиорежимах ожидается тихий тестовый тон, это не скрытый беззвучный способ удержания процесса. Действия и ошибки записываются в диагностику. Ни один новый режим пока не подтверждён на физическом iPhone. Проверяем каждый в открытом приложении, затем на главном экране и отдельно при блокировке, сохраняя ощущения пользователя вместе с отчётом. Music Haptics не используется: публичный API Apple привязан к известным записям по ISRC и не принимает наш произвольный частотный алгоритм.

Ссылки для этого эксперимента: https://developer.apple.com/documentation/corehaptics/chhapticengine/playshapticsonly и https://developer.apple.com/documentation/audiotoolbox/audio-services .

Версия 0.1.3 (сборка 4) — диагностика фоновой вибрации. В отчёте есть отдельные счётчики аудиоанализа, доставки результатов в главную очередь и принятых API ненулевых команд вибрации для состояний active/inactive/background/foreground. История из последних 40 событий фиксирует смену состояния приложения, остановки/сбросы Core Haptics и ошибки, включая события, пришедшие не из главной очереди. Успех API не доказывает физическое движение вибромотора.

«Тест фона: 12 импульсов» доступен во время воспроизведения: он передаёт Core Haptics всю последовательность сразу, временно отключая реакцию на музыку. Запусти длинную песню, проверь обычную реакцию в фоне 10 секунд и вернись. Затем нажми тест и выйди на главный экран на 6 секунд. Дождись окончания теста, повтори его с блокировкой экрана на 6 секунд. После возвращения поделись диагностикой и отдельно сообщи, ощущались ли запланированные импульсы в каждом состоянии. В этой версии не заявляется исправление фоновой вибрации; она отделяет сбой обработки от системного подавления тактильного вывода.

Версия 0.1.2 (сборка 3): исправлено сравнение URL при очистке импортов. Оно могло принять два пути к одному файлу (например, через `/var` и `/private/var`) за разные файлы и удалить выбранную копию PCM. Теперь текущий файл защищён по имени внутри каталога импортов. Тест проверяет полный цикл импорта, очистки через альтернативный путь и повторного открытия, затем повторный импорт. Диагностика показывает наличие/размер локального файла и не использует параметры предыдущего теста при ошибке открытия.

В 0.1.1 выбранный файл сначала полностью декодируется в локальный Float32 PCM CAF, затем воспроизводится. Импорт выполняется в фоне с индикатором подготовки; большой файл может потребовать времени и больше места на устройстве, чем исходный MP3/AAC. Потоковая обработка блоками ограничивает использование оперативной памяти. GitHub проверяет импорт реальных WAV и AAC: тип PCM, каналы, частоту дискретизации, длительность и сохранение сигнала, а также отказ при неверном содержимом файла. Встроенный тест уже подтверждён пользователем на iPhone; воспроизведение проблемного импортированного файла после обновления ещё нужно проверить.

Обновление 0.1.1 (сборка 2): сообщения об ошибках включают этап запуска, параметры файла/выхода и исходный код Core Audio. Добавлена проверка доступности аудиовыхода и явное соединение микшера с ним. При перезапуске не выполняется лишняя деактивация аудиосессии, а асинхронно останавливаемый движок вибрации не используется повторно. Эти изменения требуют проверки на физическом iPhone; ошибка 2003334207 сама по себе не определяет точную причину сбоя.

Установка через iloader: если AltServer возвращает −80046, открой https://iloader.app/, установи настольную Windows-версию, подключи iPhone, войди в свою учётную запись и выбери «Импорт IPA». Используй готовый BassPulse-unsigned.ipa. Перед обновлением закрой BassPulse на телефоне. Устанавливай поверх текущей версии с той же учётной записью и идентификатором приложения; не удаляй её заранее. Если установщик сообщил об успехе, проверь надпись «Прототип 0.1.1» внутри приложения.

Своя музыка → выбранные частоты → вибрация. Интерфейс на русском. Проект для iPhone 16 Pro, iOS 16 и новее; фактическую работу на iOS 27.0.1 нужно проверить на устройстве.

## Что есть в версии 0.1

- Импорт доступного аудиофайла через приложение «Файлы»: MP3, M4A/AAC, WAV и другие форматы, которые откроет AVAudioFile. Защищённые загрузки музыкальных сервисов не поддерживаются.
- Встроенный 16-секундный тест: удары 60 Гц, затем 140 Гц.
- Две независимо включаемые полосы от 20 до 1000 Гц. Реакция определяется наиболее сильной полосой; полосы не складываются и не меняют звучание музыки.
- Сила 0–100%, порог −60…−5 dBFS, резкость, короткие удары или непрерывная реакция на энергию.
- Оценка задержки аудиовыхода iOS и ручная поправка −250…+500 мс. Это приблизительная компенсация Bluetooth, а не точная синхронизация часов.
- Индикаторы энергии в полосах, сохранение настроек, передача текстовой диагностики через системное меню.

Захвата Spotify/YouTube, микрофона и видео в этой версии нет. Приложение не отправляет музыку на сервер. После импорта сохраняется одна локальная копия выбранного файла. При новом запуске приложения файл нужно выбрать снова; настройки сохраняются.

## 1. Собрать бесплатно на GitHub

Рабочий репозиторий: https://github.com/YURIIKAZ353/basspulse-ios

1. Открой вкладку **Actions**. Если GitHub предлагает включить Actions, включи их.
2. Открой **Build BassPulse IPA**. Сборка запускается после изменения ветки `main`; вручную — **Run workflow → main → Run workflow**.
3. Дождись зелёной отметки. При ошибке открой красный шаг; нужен его текст или ссылка на запуск.
4. Внизу успешного запуска, в **Artifacts**, скачай **BassPulse-IPA**. Для скачивания нужно войти в GitHub.
5. Распакуй ZIP: внутри `BassPulse-unsigned.ipa`. Это уже собрано для настоящего iPhone, но пока без подписи. AltStore подпишет его твоей учётной записью при установке.

На GitHub используется стандартная машина `macos-15`, Xcode, XcodeGen и `xcodebuild`. SDK может быть старше установленной iOS: сборка с минимальной iOS 16 может запускаться на новой iOS; новые API iOS 27 здесь не используются. Фактическую совместимость покажет запуск.

Стандартные GitHub-hosted runners бесплатны для публичных репозиториев. Исходный код этого репозитория открыт. Ключи Apple, пароль и сертификаты сборке не нужны. Не загружай их в репозиторий.

## 2. Подготовить Windows и iPhone

Используй **AltStore Classic**, а не AltStore PAL. Официальная инструкция с текущими ссылками: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows

1. Установи требуемые инструкцией Apple iTunes и iCloud. AltServer требует конкретных компонентов; не заменяй их произвольными пакетами драйверов. Если уже стоят версии из Microsoft Store или Apple Devices и возник конфликт — сначала сверься с инструкцией AltStore, не удаляй всё подряд.
2. Скачай AltServer для Windows с официального сайта https://altstore.io/ и установи его.
3. Запусти AltServer. Значок находится в области уведомлений возле часов.
4. Подключи разблокированный iPhone кабелем к Windows. Подтверди «Доверять этому компьютеру» на телефоне. В iTunes включи синхронизацию с этим iPhone по Wi-Fi.
5. В меню значка AltServer выбери **Install AltStore → твой iPhone**. Введи свою учётную запись Apple в окне AltServer. Пароль и код подтверждения не присылай в чат.
6. На iPhone открой **Настройки → Основные → VPN и управление устройством** и доверься профилю своей учётной записи, если iOS этого требует.
7. Открой **Настройки → Конфиденциальность и безопасность → Режим разработчика**, включи его и подтверди после перезагрузки. Если пункта пока нет, заверши попытку установки AltStore и проверь ещё раз.

Настройки и сообщения могут отличаться на iOS 27.0.1. Поддержку конкретной связки iOS и текущего AltServer нужно подтвердить установкой. При ошибке сохрани её точный текст; не покупай платную подпись для обхода непонятной ошибки.

## 3. Установить BassPulse

1. Передай `BassPulse-unsigned.ipa` в «Файлы» iPhone — например, через iCloud Drive. Либо скачай ZIP артефакта GitHub в Safari на iPhone и распакуй нажатием в «Файлах».
2. Оставь AltServer запущенным на Windows; для первой установки оставь iPhone подключённым кабелем.
3. В AltStore открой **My Apps → +**, выбери `.ipa`. При запросе войди в свою учётную запись Apple.
4. Дождись установки и открой BassPulse.

У бесплатной подписи срок семь дней. Обновляй приложение через **Refresh All** в AltStore при доступном AltServer. Обычный бесплатный аккаунт допускает до трёх таких приложений одновременно, включая AltStore. У BassPulse нет расширений, чтобы не расходовать дополнительные идентификаторы.

## 4. Первый тест

1. Подключи Bluetooth-наушники до запуска воспроизведения. Уменьши громкость до комфортного уровня.
2. В BassPulse нажми **Тест вибрации**. Должен быть один короткий импульс с выбранной силой.
3. Нажми **Загрузить тест 60 → 140 Гц**, затем **Играть**. Первые восемь секунд — 60 Гц, следующие восемь — 140 Гц; удары идут каждые полсекунды.
4. Отключи полосу 2: реакция во второй половине должна заметно ослабнуть. Фильтры имеют плавные склоны, поэтому они не дают математически резкого отсечения соседних частот.
5. Поменяй силу, порог и режим. «Удары» ищет подъёмы энергии, а не распознаёт музыкальный темп; «Энергия баса» следует огибающей.
6. Если вибрация опережает слышимый удар, увеличивай поправку задержки. Если отстаёт — уменьшай. Начни с шагов 20–40 мс.
7. Открой свой MP3/M4A/WAV через **Выбрать аудио из Файлов**. Загрузки Spotify и Apple Music внутри их приложений не являются доступными для импорта аудиофайлами.

## 5. Проверка фона — отдельный эксперимент

Приложение заявляет фоновое воспроизведение аудио. Это не гарантирует фоновую вибрацию. Нам нужны три отдельных результата:

| Состояние | Звук продолжается? | Вибрация продолжается? |
|---|---|---|
| BassPulse открыт | Да / нет | Да / нет |
| Открыто другое приложение, которое не воспроизводит звук | Да / нет | Да / нет |
| iPhone заблокирован | Да / нет | Да / нет |

Проверяй по 5–10 секунд в каждом состоянии на встроенном тесте, заново запуская его при необходимости. Не включай Spotify параллельно для этой проверки: аудиосессия BassPulse пока эксклюзивная, а запуск другого проигрывателя может её прервать. После отключения наушников приложение останавливается; снова нажми «Играть».

Если вибрация остановилась, вернись в приложение, сохрани текст раздела диагностики до следующего запуска и нажми «Поделиться диагностикой». Возобновление после системной остановки выполняется вручную через «Стоп → Играть». Приложение не маскирует системный запрет бесконечными перезапусками.

## Проверки и архитектура

- `Sources/DSP.swift`: фильтрация каналов по отдельности, RMS в каждой полосе, порог, сглаживание, детектор подъёма энергии. Противофазный стереобас не пропадает при сведении каналов.
- `Sources/AudioController.swift`: импорт, AVAudioEngine, обработка смены выхода/прерываний, очередь команд с отменой после остановки.
- `Sources/HapticOutput.swift`: Core Haptics на главной очереди, пульсации и непрерывный режим.
- `Tests/main.swift`: проверяет реальный Swift-код DSP на частотах 60/1000 Гц, 44,1/48 кГц, противофазном стерео, выключенных полосах, серии ударов и пустом входе.
- `.github/workflows/build-ios.yml`: тест DSP, компиляция для `iphoneos`, упаковка `Payload/BassPulse.app` в IPA. Проверки на симуляторе не доказывают работу вибрации.

На Windows без Swift/Xcode iOS-компиляция не выполняется. Подтверждение сборки — зелёный запуск Actions. Подтверждение тактильного поведения — физический iPhone.
